# DriveDeck UI previews

The screenshots in this directory are standards-compliant SVG 1.1 documents with explicit `width`, `height`, and `viewBox` attributes. They stay text-only because the repository's pull-request transport rejects binary files. SVG file size is intentionally small: vector paths remain sharp at 1024×600, 1920×1080 and larger resolutions without embedding raster data.

Every preview is parsed as XML during repository validation. Open the raw SVG file in a browser if a Markdown client does not render SVG images inline.
